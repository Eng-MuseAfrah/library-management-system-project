# 📚 Library Management System

A modern and responsive **Library Management System** built with **HTML, CSS, and JavaScript**.  
The system is designed to simplify the management of books, members, borrowing, and returning transactions through a clean and user-friendly interface.

---

## 🚀 Project Overview

The Library Management System is a web-based application that helps libraries organize and manage their daily activities digitally.

Instead of managing books and borrowing records manually, this system provides an organized interface for managing:

- 📖 Books
- 👥 Library Members
- 📚 Borrowing Transactions
- 🔄 Returning Books
- 📊 Library Information

The project focuses on creating a simple, responsive, and easy-to-use library management experience.

---

## ✨ Features

### 📖 Book Management
- Add and manage library books
- Display available books
- View book information
- Track book availability

### 👥 Member Management
- Manage library members
- Store member information
- View registered members

### 📚 Borrowing Management
- Record borrowed books
- Connect books with members
- Track borrowing transactions
- Monitor borrowed books

### 🔄 Returning Management
- Record returned books
- Update book availability
- Track completed transactions

### 📱 Responsive Design
- Fully responsive layout
- Works on desktop, tablet, and mobile devices
- Clean and user-friendly interface
